## 2. GraspNet 与 UR7e 夹爪轴定义

GraspNet 局部轴语义：

| GraspNet 局部轴 | 源码语义 |
| --- | --- |
| X / 第 0 列 | 接近方向、depth 方向 |
| Y / 第 1 列 | 两指开合宽度方向 |
| Z / 第 2 列 | 夹爪高度方向 |

当前 UR7e 夹爪 TCP 约定：

| UR7e TCP 轴 | 现场语义 |
| --- | --- |
| Z | 垂直法兰面 |
| X | 平行夹爪开合方向 |
| Y | 垂直夹爪开合方向 |

因此第一轮实机验证默认使用：

```json
"tcp_rotation_mode": "current"
```

也就是先保持当前夹爪姿态，只验证位置链路和高度。若后续要让 TCP 姿态跟随 GraspNet，应切换到：

```json
"tcp_rotation_mode": "graspnet"
```

并现场标定/验证 `tcp_rotation_offset_matrix`，不要直接假设 GraspNet 三个局部轴和 UR TCP 三个轴天然一致。

## 3. 已落实的要求

| 要求 | 当前实现 |
| --- | --- |
| 仅使用腕部相机 | `camera.serial=419122270341`，代码只启动 `WristRealSenseCamera` |
| 中心矩形掩码 | `workspace_mask.width_fraction=0.5`、`height_fraction=0.5`，RGB 外部置黑，depth 外部置 0 |
| 固定随机种子 | `random_seed=20260531`，发送给 GraspNet HTTP 服务 |
| 腕部预览画面 | `preview.py` 在腕部图像上画中心掩码框和抓取姿态轴，并保存 `outputs/last_wrist_preview.png` |
| 输出夹取点位 | `pipeline.py` 打印并保存 `current_tcp`、`grasp_center_base`、`tcp_pregrasp`、`tcp_goal` |
| 从当前点位到抓取点位变化 | `--execute` 时通过 XML-RPC 依次执行 `pregrasp` 和 `grasp` |
| 每次先到固定点位 | `motion.fixed_start_tcp` 配置固定观察位；若执行时仍为 `null`，程序拒绝运行 |
| 根据 eye-in-hand 标定动态转换 | `T_base_cam_now = T_base_tcp_now @ T_tcp_cam` |
| 不依赖旧复现代码 | 所有逻辑在本目录 `src/eye_in_hand_graspnet/` 内独立实现 |

## 4. 运行流程

1. 如果要实机执行，先在 `configs/eye_in_hand_ur7e_wrist.json` 填写 `motion.fixed_start_tcp`。
2. 启动 GraspNet-baseline HTTP 服务，并确认接口字段和 `graspnet.*_field` 配置一致。
3. 先干跑：

```powershell
python scripts\run_wrist_grasp_cycle.py --dry-run
```

4. 检查 `outputs/last_wrist_grasp_result.json`：

```text
camera.serial == 419122270341
mask.kept_pixels / mask.total_pixels == 0.25
target.T_base_cam_now 存在
target.grasp_center_base 合理
target.tcp_pregrasp 和 target.tcp_goal 相对 current_tcp 跳变量合理
```

5. 首次实机只允许低速移动到 `start` 或 `pregrasp`。
6. 确认方向和高度后，再开放 `grasp`。

## 5. 当前配置中需要现场确认的项

```text
motion.fixed_start_tcp
motion.xmlrpc_url
motion.move_tcp_method
motion.move_tcp_kwargs
graspnet.url
grasp.tcp_translation_offset_m
grasp.tcp_rotation_offset_matrix
```

其中 `tcp_translation_offset_m` 是“GraspNet 抓取中心 -> UR TCP 原点”的偏移，按最终 TCP 坐标系表达。它不是法兰盘到 TCP 的变换。

## 6. 安全注意事项

- 首次不要直接闭合夹爪。
- 机器人拍照时必须静止，否则当前 TCP 和图像不同步。
- 不要使用固定相机序列号 `254522072098` 的 GraspNet 结果走这条链路。
- 如果示教器 TCP 绑定再次从夹爪 TCP 切回法兰盘中心，本配置中的 `T_tcp_cam` 语义会失效。
- 如果 GraspNet 服务不接受 multipart 的 `color/depth/workspace_mask/intrinsics/factor_depth` 字段，先改客户端适配服务接口，再做实机测试。
