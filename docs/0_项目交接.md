# 项目交接：腕部相机 Eye-in-Hand GraspNet UR7e 复现

## 当前目标

本目录要完成一条独立的腕部相机抓取链路：

```text
腕部 RealSense RGB-D
  -> 中心矩形工作区掩码
  -> GraspNet-baseline HTTP 推理
  -> RTDE 读取当前夹爪 TCP
  -> T_base_cam_now = T_base_tcp_now @ T_tcp_cam
  -> 输出/执行 UR7e TCP 抓取点位
```

本工程不依赖 `reproduction/graspnet-baseline-in-ur7e` 的代码。需要的相机、掩码、GraspNet 客户端、RTDE、XML-RPC 和坐标变换逻辑已经放在本目录 `src/eye_in_hand_graspnet/`。

## 主入口

无硬件烟测：

```powershell
python scripts\smoke_test_no_hardware.py
```

连相机、GraspNet 服务和 RTDE 后先干跑：

```powershell
python scripts\run_wrist_grasp_cycle.py --config configs\eye_in_hand_ur7e_wrist.json --dry-run
```

实机移动必须显式使用：

```powershell
python scripts\run_wrist_grasp_cycle.py --config configs\eye_in_hand_ur7e_wrist.json --execute
```

## 当前配置约定

- 腕部相机序列号：`419122270341`。
- 掩码：只保留图像中心宽高各 1/2 的矩形区域，其余 RGB 置黑、depth 置 0。
- 随机种子：`20260531`，通过 `graspnet.seed_field` 发送给 GraspNet 服务。
- 标定矩阵：`configs/eye_in_hand_calibration_tcp.json/T_tcp_cam`。
- 默认 TCP 姿态策略：`grasp.tcp_rotation_mode = current`，先保持当前夹爪姿态，只验证位置链路。
- 默认 TCP 偏置：`tcp_translation_offset_m = [0,0,0]`，表示暂时假设 UR TCP 原点就是视觉抓取中心；实机前需要按夹爪结构复核。

## 实机前必须填写

`configs/eye_in_hand_ur7e_wrist.json` 中的：

- `motion.fixed_start_tcp`：固定观察点位 `[x,y,z,rx,ry,rz]`，当前为 `null`。如果 `--execute` 且 `enabled_steps` 包含 `start`，程序会拒绝运行。
- `motion.xmlrpc_url`：XML-RPC 控制服务地址。
- `motion.move_tcp_method` 和 `motion.move_tcp_kwargs`：必须和现场 XML-RPC 服务实际接口一致。
- `graspnet.url`：GraspNet HTTP 推理服务地址。
- `grasp.tcp_translation_offset_m`：从 GraspNet 抓取中心到 UR TCP 原点的偏置，按最终 TCP 坐标系表达。

## 推荐调试顺序

1. 运行无硬件烟测，确认配置和坐标变换代码没有语法或基本逻辑错误。
2. 启动 GraspNet 服务，单独用 `--dry-run` 确认腕部相机能返回 `best_grasp`。
3. 检查输出的 `camera.serial` 必须是 `419122270341`。
4. 检查 `outputs/last_wrist_grasp_result.json` 中的 `T_base_cam_now`、`grasp_center_base`、`tcp_pregrasp`、`tcp_goal`。
5. 首次实机只允许移动到 `start` 或 `pregrasp`，低速、张开夹爪，不闭合。
6. 方向和高度确认后，再开放 `grasp` 步骤。

## 当前风险

- GraspNet HTTP 服务的真实字段名可能和配置默认值不一致。若服务不是 multipart 接口，需要改 `graspnet_client.py` 或配置。
- XML-RPC 服务是否支持 `move_tcp(pose, kwargs)` 需要用现场服务确认。
- `tcp_rotation_mode=current` 能降低姿态风险，但不等于最终可抓取姿态；要跟随 GraspNet 姿态时，需要现场确认 `tcp_rotation_offset_matrix`。
- 标定结果绑定的是“夹爪 TCP”，如果示教器 TCP 定义再次变化，需要重新确认或重新标定。
